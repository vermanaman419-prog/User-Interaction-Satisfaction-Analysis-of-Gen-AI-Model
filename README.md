# 📊 User Interaction & Satisfaction Analysis of Gen AI Agent 
## 📌 Project Overview

This project analyzes user interaction, response performance, and satisfaction for a Generative AI system using a realistic dataset.

# The goal is to understand:

- How different user segments experience the AI

- What drives customer satisfaction

- Where product and performance improvements are needed

- Whether subscriber users behave differently from free users

# The analysis follows an end-to-end data analyst workflow:

- Data cleaning & preparation using Python.

- Exploratory Data Analysis (EDA).

- Necessary Visualizations using python.

- Business insights

- Dashboard creation in Tableau


# 🗂 Dataset Description

The dataset contains ~2000 user interactions with the following key fields:

- Subscription Type (Free / Subscriber)

- Question Category (Coding, Medical, Finance, etc.)

- Response Time (seconds)

- Customer Satisfaction Score (1–5)

- Country

- Age Group

- Device Type (Android, iOS, Web)

- Model Version (Gemini-1.0, Gemini-1.5, Gemini-Pro)
